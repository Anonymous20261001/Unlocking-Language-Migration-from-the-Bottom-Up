三、总结
================================================================================

翻译管道（5867 个 compile_status=pass 的条目）：
  - 编译通过率：99.7%（仅 16 个链接失败）
  - 行为一致性：94.9%（5554 PASS + 284 INCONSISTENT + 13 CRASH）
  - INCONSISTENT 主要是 C++ wrapper 值语义与 Java 引用语义的差异

原始骨架质量（1274 个 compile_status=fail 的条目）：
  - 主要问题：LLM 生成 wrapper 时的类型/成员错误（29%）、语法错误、缺头文件
  - 最集中的问题类：Scanner、MetalLookAndFeel、BigInteger 等复杂 API
  - 根本原因：原始 translate_java_to_cpp.py 的 one-shot LLM 翻译对复杂类精度不足
